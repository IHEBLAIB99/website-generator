# Website Generator

Pick a business type and get a working sample website in one click.

Types: restaurant, hair salon, gym, law firm, photographer, online store.

Each generated site includes illustrated images, a gallery with an image viewer, a team section, a review slider, an FAQ, a select/add-to-cart list and a contact form with a confirmation message. The form is a demo and sends nothing.

## Run it

Open `index.html` in any browser. No build step or dependencies.

## Use it

1. Choose a business type.
2. Optionally enter a business name.
3. Click **Generate website**, then **New look** for another style, or **Copy HTML** to take the code.
